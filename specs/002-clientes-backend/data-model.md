# Data Model: Cadastro de clientes

## Tabela `clientes` (migration V4)

Tem as mesmas colunas de `medicos`, trocando `crm`/`especialidade` por `cpf`/`data_nascimento`:

| Coluna | MySQL (`db/migration`) | PostgreSQL (`db/postgresql`) |
|---|---|---|
| id | `bigint not null auto_increment` | `bigint generated by default as identity` |
| nome | `varchar(100) not null` | igual |
| email | `varchar(100) not null unique` | igual |
| telefone | `varchar(20) not null` | igual |
| cpf | `varchar(11) not null unique` | igual |
| data_nascimento | `date not null` | igual |
| logradouro, bairro, cidade | `varchar(100) not null` | igual |
| cep | `varchar(9) not null` | igual (mesmo tamanho de `medicos`) |
| complemento | `varchar(100)` | igual |
| numero | `varchar(20)` | igual |
| uf | `char(2) not null` | igual |
| ativo | `tinyint not null` | `boolean not null` |

## `Cliente` (entidade, `cliente/`)

Os campos acima mais `@Embedded Endereco endereco`. Comportamentos, espelhando `Medico`:

- `Cliente(DadosCadastroCliente)`: nasce `ativo = true`.
- `atualizarInformacoes(DadosAtualizacaoCliente)`: altera nome, telefone e endereço, ignorando `null`.
- `excluir()`: `ativo = false`. `ativar()`: `ativo = true`.

## DTOs

### `DadosCadastroCliente`

| Campo | Regras (mensagem) |
|---|---|
| nome | `@NotBlank` (é obrigatório), `@Size(max=100)` (deve ter no máximo 100 caracteres) |
| email | `@NotBlank`, `@Email` (deve ser um e-mail válido), `@Size(max=100)` |
| telefone | `@NotBlank`, `@Size(max=20)` |
| cpf | `@NotBlank`, `@Pattern(\d{11})` (deve ter 11 dígitos, sem pontuação), `@CPF` (CPF inválido) |
| dataNascimento | `@NotNull` (é obrigatório), `@Past` (deve ser uma data no passado) |
| endereco | `@NotNull @Valid DadosEndereco` (reuso) |

### `DadosAtualizacaoCliente`

| Campo | Regras |
|---|---|
| id | `@NotNull` |
| nome | `@Pattern(".*\\S.*")` (não pode ficar em branco), `@Size(max=100)` |
| telefone | `@Pattern(".*\\S.*")`, `@Size(max=20)` |
| endereco | `@Valid DadosAtualizacaoEndereco` (reuso) |

### Saída

- `DadosListagemCliente(Long id, String nome, String email, String cpf)`
- `DadosDetalhamentoCliente(Long id, String nome, String email, String telefone, String cpf, LocalDate dataNascimento, DadosEndereco endereco, Boolean ativo)`

## `ClienteRepository`

`findAllByAtivoTrue(Pageable)`, `findAllByAtivoFalse(Pageable)`, `existsByCpf(String)`, `existsByEmail(String)`.

## `ClienteService`

| Método | Regra |
|---|---|
| `cadastrar` | `validarDuplicidade` (CPF e depois e-mail) e então `save`, com `@Transactional` |
| `listar` / `listarInativos` | mapeia para `DadosListagemCliente` |
| `detalhar(id)` | `buscarClientePorId`, que lança `EntityNotFoundException("Cliente não encontrado: " + id)` |
| `atualizar` / `excluir` / `ativar` | `buscarClientePorId` e o método da entidade, com `@Transactional` |

## Estados

```
[cadastrado] ──► ativo ──excluir──► inativo ──reativar──► ativo
```
